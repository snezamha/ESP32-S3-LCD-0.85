# ESP32-S3-LCD-0.85 Framework

A reusable framework for the Waveshare ESP32-S3-LCD-0.85 board.

## Lesson 11: screens and state

- Use `PLUS` and `MINUS` to move between Home, Counter, and Settings.
- On Counter, press `PWR` to enter or leave edit mode.
- In Counter edit mode, `PLUS` and `MINUS` change the value.
- Hold `MINUS` in edit mode to reset the counter.
- Hold `PLUS` in edit mode to add five.
- Hold `PWR` anywhere to switch the device off through the battery latch.
